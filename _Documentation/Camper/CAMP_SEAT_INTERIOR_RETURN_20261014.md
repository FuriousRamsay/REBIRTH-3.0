It projects the original point through the current camper transform, verifies the authored interior floor remains present, and checks a native-controller-sized upright capsule against solid geometry including the camper hull, furnishings, world and other players. Own-player colliders and triggers are excluded. A small contact allowance avoids rejecting the supporting floor; unsafe points retain the native exterior exit. A successful return uses native SetPosition, SetRotation, ResetLastTickPos and controller Stop. No native camera or attachment logic is skipped.

Two confirmed source mismatches were corrected. Native local SetPosition directly supplies that controller Transform, confirming the matching restore coordinate. Queries previously used Physics.AllLayers, which can reject colliders ignored by actual player movement; floor and capsule queries now derive the actual CharacterController layer collision mask and filter Physics.GetIgnoreCollision pairs.
