# Plough bracket black-face investigation

Read-only source binary and actual Unity candidate audits agree: 9,786 significant triangles have no normal/winding disagreement; all 176,114 tangent frames pass finite/length/orthogonality/handedness checks. Two hundred degenerate triangles are present in the approved source but are not responsible for the large black support faces. Albedo is nonblack at those support UVs, while the loaded 256px occlusion map gives zero ambient visibility on some exposed faces. Example: support at (-.780,.5353,1.978), UV(.17446,.56619), baked AO0 versus actual 64-ray hemisphere geometric AO.875. Other genuinely enclosed faces have geometric AO0 and should retain contact darkness.

Actual same-camera Unity original/no-AO/no-normal-map isolation renders are under `E:/_Haven/shared/REBIRTHStaged/CamperCorrections_20261021/PloughSurfaceAudit`. Removing only AO reveals the support surface texture; removing the normal map does not fix that occlusion. These toggles are diagnostic, not the proposed production correction.

`RebirthCamperPloughAORepair.cs` performs a scoped 1024px UV-space geometric AO rebake with 32 cosine-weighted hemisphere rays per covered texel, radius .30m, bias .003m, backface queries and 8px island padding. It preserves actual zero-AO enclosed regions and does not clamp the map to an artificial brightness. The resulting linear texture replaces only the occlusion map on a cloned Standard material, AO strength remains1. Every matching plough renderer/LOD receives the clone. Source mesh/UV/normals, all other material maps/color, and serialized Collider/Rigidbody signatures remain unchanged.

The coordinated Unity run completed14,325,024rays over447,635coveredtexels/100,446UVfaces. Three matching plough material/LOD receivers were assigned. The exposed bracket sample changed AO0 to .83212 (independent64-ray reference.875); truly enclosed faces remain0. After-render was inspected and retains rust/normal detail with false occlusion removed. Receipt: plough-ao-receipt.txt. Original baseline diagnostics were preserved in PloughSurfaceBefore; corrected diagnostics are in PloughSurfaceAudit.

Only the versioned `Assets/REBIRTHPickupRearCornerCandidate_20261021_v1` prefab/material/texture candidate is written. Original approved assets and the installed bundle are not edited by the script. A final combined bundle and reopen audit are still required; the script is not itself an installation or gameplay pass. Native relay lifecycle checks are a separate Unity audit using actual production source with native interfaces doubled.
