# Rear reverse illumination

The camper rear lamp beams were limited to intensity0.65,4m range and48-degree spot angle. They now use fivefold beam intensity3.25,6m range and60-degree angle only while genuinely reversing with a working lamp part. Lens emission remains0.65, brake/tail/marker behavior stays unchanged, and forward headlights are untouched. The camper retains its existing red rear-light convention; the separate bare-pickup clear reverse segments remain white. No color channel or original geometry was removed.

Rear-light emission cache previously treated reverse and braking identically because both use0.65. The cache now explicitly invalidates when the reverse profile changes, so leaving reverse restores the original brake/tail range, angle and intensity rather than retaining a boosted beam. Broken lights, nonfinite velocities and non-reverse movement cannot activate the reverse boost.

The screenshot's circled black/chrome cylinders are not generated by the illumination code: camper rear emitters are empty GameObjects containing only Light components; runtime pickup emitters likewise contain only a Light, and no cylinder primitive is created. Original round rear-lamp metal housing geometry remains in the source model. The image is consistent with those original housings; this note does not claim a new mesh audit of their exact triangles or delete them based on appearance.

Validation: `dotnet run --project Tools/CamperRearLightTests/CamperRearLightTests.csproj` links the actual production policy, checking reverse threshold, invalid inputs, broken-light behavior and unchanged brake/tail/marker/pickup channel behavior. No game, bundle, heavy Unity job or root DLL build was run here.

Manual scenario (NOT RUN): at night on a disposable flat road, compare stationary tail lights, brake, actual reverse, then brake again and forward. Verify much brighter rear-ground illumination and slightly wider cone only during reverse, without stuck boosted lights. Repeat fitted camper and bare pickup, headlights on/off and broken light part; camper remains red and pickup clear reverse remains white. Inspect both original rear lamp housings before any geometry change.

Files: `RebirthCamperRearLights.cs`, `RebirthCamperLampIntensity.cs`, new `Tools/CamperRearLightTests` project/source, and this note. Visual intensity values are implemented; native rendered-night acceptance remains to be tested.
