# Rear reverse illumination

The camper rear lamp beams were limited to intensity0.65,4m range and48-degree spot angle. They now use fivefold beam intensity3.25,6m range and60-degree angle only while genuinely reversing with a working lamp part. Lens emission remains0.65, brake/tail/marker behavior stays unchanged, and forward headlights are untouched. The camper retains its existing red rear-light convention; the separate bare-pickup clear reverse segments remain white. No color channel or original geometry was removed.

Rear-light emission cache previously treated reverse and braking identically because both use0.65. The cache now explicitly invalidates when the reverse profile changes, so leaving reverse restores the original brake/tail range, angle and intensity rather than retaining a boosted beam. Broken lights, nonfinite velocities and non-reverse movement cannot activate the reverse boost.
