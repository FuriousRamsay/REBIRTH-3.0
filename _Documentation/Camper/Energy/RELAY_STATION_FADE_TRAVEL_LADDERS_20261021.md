# Relays follow station fade; fitted ladders work in Travel

The user's later explicit visibility instruction supersedes earlier Travel-visible relay notes: native relays now fade in with stations during deployment, remain fully visible and interactable in Camp, and fade away with stations while packing to Travel. They are hidden in Travel. Their exact red-stripe midpoint placement, native half-size geometry and seated skin position are retained.

Appearance appends the completed relay group to its existing `FadeGroups`/`FadeRenderers` arrays, including when the native relay asset arrives after initial binding. The same mode observation, duration, smoothed `view.Opacity`, property-block update and final Travel deactivation apply. No independent relay timer, animation or alpha system was added. Native relay materials are cloned to the already bundled `REBIRTH/CamperCampFade` shader, following the existing station material authoring contract, so `_CampVisibility` affects them. Source materials are never mutated; the relay group's lifetime component destroys only its own material clones. New relays start hidden until Appearance applies the current station opacity. Their wire trigger colliders enable only in fully deployed Camp, like physical station targets.

Separately, `RebirthCamperRearLadders.Contains` previously rejected every energy mode except Camp. It now admits the existing native ladder movement path in both Travel and Camp when the camper body is fitted. Bare pickups, hidden geometry, transitions, seated/flying/dead actors, wrong world/model, stale vehicle identity and distant players retain their existing refusal rules. This does not expose Camp-only crafting equipment or change vehicle physics/jump parameters.

Validation: the fixture directly linking production ladder/geometry/focus sources passes73 checks with actual exported camper skin input, including Travel/Camp ladder admission, bare/transition/hidden/seated refusals and red-stripe-centered mounting on both sides. Four static relay fade contracts verify the shared station path, native material ownership, late binding and deployed-only trigger behavior. The Unity lifecycle audit source was updated for Appearance-owned initial activation and fade material properties but was not rerun in Unity by this subtask. No game or root DLL build was performed.
