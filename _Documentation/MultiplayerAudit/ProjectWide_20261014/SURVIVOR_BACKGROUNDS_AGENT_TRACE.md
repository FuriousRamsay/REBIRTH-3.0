A qualified owner can request provenance/durability for an existing eligible item using its triple and a valid recipe producing that type. This is an active authenticated-client claim boundary, not a request to change another player's record. No forging packet/game test was run. The fix scope, if authorized later, is binding this stamp to an existing verified native output receipt; do not rewrite general inventory authority or remove original owner craft handling.
