## Native image, input and queue semantics

InputLayout stages3->9 physical expansion and shifts material counter cells to9+ without mutating originals. AlignedInputMigration requires identical material count/order/names, no duplicates, matching lastInput/timer dimensions and finite timers before staging all three arrays. No caller was found for AlignedInputMigration in source searches, so it must not be described as an installed live migration. Material counters retain Int32 counts in their explicit XML transaction codec; physical slots remain native UInt16-bounded.

GridSnapshotCodec validates at most9 physical cells, native item canonical roundtrip, count<=65535, bounded text and metadata<=255; preserves null/empty and zero-count nonempty item payloads. MaterialInputCodec adds typed counters and physical slot count; it is transaction-image encoding, not replacement native world serialization. NativeInputCodec roundtrips physical stack-array wire format and compares full item snapshots. NativeInputSnapshot/NativeQueueSnapshot are bounded exact wire/observation images, not immutable mutation leases or durable receipts. Queue observation additionally retains fields omitted by native serialization; its separate wire image is what MatchesSerializedQueue compares.

GridIngredients clones exact admitted stacks and full recipe fields; shared Effects reference is not independently frozen by this helper. Physical plan aggregates native type quantities, rejects foreign extra inputs/installed mods, uses validated quantity modifiers and overflow checks, and constructs detached remainder only against full snapshot equality. Material plan verifies exact unit_<material> counter identity and preserves zero-count counter item values. TryBuildQueueRecipe bounds output count/time/XP, disables repeat modifiers, stamps the queue binding and retains paid fragment provenance. These helpers do not acquire a lease or publish a durable debit.

InputPaymentImage merges only against the original exact snapshot, never increases counts, keeps physical items unchanged in material-payment mode and preserves counter offsets. NativeQueueEntry searches vacant native entries, rejects duplicate marked job ids, stages one entry with correct tail IsCrafting, and stages cancellation only against admission/intent/actor/quality/multiplier evidence. Unrelated rows are shared objects in its replacement image by design; caller must recheck whole native queue at commit. NativeQueueSnapshot supplies that observation primitive. These are sound local controls, not evidence that all parent admission/refund paths publish atomically.

LiveAccess is authority-thread/current-world/current-entity/complete-character/creation/identity gated. Placed path requires8m finite distance, exact live station, exclusive lock channel0 and workstation security ACL. Mobile path requires full address/current lease and rechecks station/lease/owner after identity callbacks. It does not silently reinterpret coordinates as a camper. No change to this accepted architecture is proposed.
