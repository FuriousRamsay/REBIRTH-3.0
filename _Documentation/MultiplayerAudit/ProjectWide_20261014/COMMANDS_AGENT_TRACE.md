## Side effects and test safety

rbdrone/rbdronequality executes server-side by native default. Resolves authenticated RemoteClientInfo.entityId first, otherwise primary local player; dedicated console with no issuing player refuses. Selects requested/nearest living drone only when belongsPlayerId matches issuing entity, including owned list check for nearest. It sets/clears per-entity RebirthDroneQualitySpeed overrides1–2x or quality tiers1–6. Explicit float finite checks prevent NaN/Infinity overrides/durations; trace ranges1–60seconds and2–30Hz. Telemetry duration finite check delegates bounds to service. These are deliberate real motion-policy/session changes, not read-only reports. SetDebugOverride writes dictionary, GetAppliedMultiplier consumes it, ResetForWorldChange clears it; no durable save/network payload authored by wrapper. Trace start/stop is deliberate diagnostics, no wrapper teleport/attack. ResolveSenderPlayer fallback to host if a nonnull remote sender fails resolution is a source trust weakness conditional on native remote command dispatch before entity existence; native sender lifecycle reachability is not newly established, so not promoted as ownership bypass. Actual drone runtime was previously fully read in COMPANIONS trace; no duplicate service full-read count.

rbpickup/rbblockpickup has status/report, clearcache and lagtest branches. clearcache changes classifier and service caches; it is not a passive status query. lagtest off writes a one-shot file via installer SetLagTestDisabled under GameIO.GetUserGameDataDir, not current save directory; on deletes that file. Consumer reads/deletes exact payload at next startup, legacy payload is cleared without disabling. Command clearly says current process unchanged/restart required. Therefore this diagnostic persists across saves and can change next process startup, intentionally; no command was run here. Error catches/logging do not prove deletion succeeded. It is client-routed: remote owner schedules its own local installation test, listen host local invocation schedules host process; do not assume it schedules remote dedicated server. Default branch only describes actual targeted parent multiblock and uses primary local world/crosshair.

rbtogglestatefresh on/off/reset mutates in-memory shadow dictionary matching module registry, no gameplay enable/patch call; selective setter/reset read verified this instead of accepting help as sole proof. rg -uuu consumers are module manifests, build profile selection, Debug dry-run reports. rbruntimetogglesfresh reset replaces explicit-default shell snapshots under lock; rbharvestpolicyfresh reset increments policy version/reason and replaces default snapshot. These report-shell state mutations are real but distinct from gameplay or durable save. The wrapper claims 'read-only' on togglestate description is imprecise for shadow state; no active multiplayer gameplay defect proved.

rbspawn simulate validates count1–1000000, parses integer gamestage and seeded Random, invokes composition simulation; explain calls TrySelectDetailed with HistoryKey=null. No EntityFactory, world SpawnEntity, save or packet call authored in wrapper. POI risk/sense reads primary local actor and delegates policy snapshot/report.
